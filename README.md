
## Wallet connect

Any injected EVM wallet (EIP-6963: MetaMask, Rabby, Coinbase, Phantom, Brave, OKX, and others) and injected Solana wallets connect from the title screen. Mobile wallets use WalletConnect. Set `VITE_WALLETCONNECT_PROJECT_ID` or paste a project id from https://cloud.reown.com in the connect panel.

Settings holds wallet connect, the glass-mark shop, four save slots, and a room-code multiplayer lobby. Signaling is /api/rtc.
